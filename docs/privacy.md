# Privacy

CreativeLift AI is privacy-first and self-hostable.

Principles:

- no non-essential cookies by default
- collect only measurement events needed by the operator
- support anonymous IDs and user IDs
- keep retention configurable
- avoid logging secrets or raw API keys
- document connector data flows

This project is not legal advice. Operators are responsible for privacy, advertising, AI disclosure, and sector-specific compliance.
