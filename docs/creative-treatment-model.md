# Creative Treatment Model

A Creative Treatment is the central object in CreativeLift AI.

It includes:

- brief
- objective
- target audience
- channel and placement
- angle, hook, CTA, offer, and copy
- media metadata
- AI model and provider
- prompt lineage
- brand guardrails
- approved claims and evidence
- human edits
- approval and compliance status
- experiment assignment
- event data
- spend, revenue, conversion metrics
- incremental lift estimate
- decision recommendation

Treatments are versioned through `creative_versions` and connected to prompt provenance through `prompt_runs`.
